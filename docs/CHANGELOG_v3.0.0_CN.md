# Sol-Green 更新日志 v3.0.0

## 🎉 版本概述

Sol-Green v3.0.0 是一个功能完整的企业级环保 Web3 平台，包含核心功能、挑战活动、营销活动、运营管理、多链支持和合约升级等完整功能。

## 🔧 配置说明

### 默认环境

项目默认部署在 **Solana 测试环境 (Devnet)**，通过 `ENVIRONMENT=test` 配置。

### 环境切换

```bash
# 测试环境（默认）
ENVIRONMENT=test

# 主网环境
ENVIRONMENT=mainnet

# 开发环境
ENVIRONMENT=dev
```
