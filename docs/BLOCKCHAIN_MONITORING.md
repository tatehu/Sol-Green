# 区块链数据监听系统

## 📋 概述

区块链数据监听系统实时监听链上事件，获取运行数据，为运营决策提供数据支持。

## 🔍 监听内容

### 1. 交易监听

- **奖励发放交易**: 监听代币转账交易
- **存证交易**: 监听链上存证交易
- **合约调用**: 监听智能合约调用

### 2. 账户监听

- **程序账户变化**: 监听智能合约账户数据变化
- **用户账户余额**: 追踪用户代币余额
- **管理员账户**: 监控管理员账户状态

### 3. 事件监听

- **RewardMinted**: 奖励发放事件
- **ProofRecorded**: 存证记录事件
- **ChallengeCompleted**: 挑战完成事件

## 🔧 实现方式

### WebSocket 订阅（推荐）

```go
// 订阅账户变化
wsClient.AccountSubscribe(programID, rpc.CommitmentFinalized)

// 订阅程序日志
wsClient.LogsSubscribe(programID)
```

### 轮询模式（备用）

```go
// 定期轮询交易
GetSignaturesForAddress(programID)
GetTransaction(signature)
```
