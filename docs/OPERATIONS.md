# 运营管理系统

## 📋 概述

运营管理系统为运营者提供数据统计、分析报告、活动管理等工具，帮助提高项目活跃度和运行效率。

## 📊 数据统计

### 基础统计

- **总用户数**: 平台注册用户总数
- **活跃用户数**: 指定时间段内有行为的用户数
- **总行为数**: 环保行为提交总数
- **总奖励**: 奖励发放总额

### 链上统计

- **当前区块高度**: Solana 当前 slot
- **程序账户状态**: 智能合约账户信息
- **交易数量**: 链上交易统计
- **网络状态**: 链上网络健康度

## 📈 数据分析

### 日报

- 当日新增用户
- 当日行为提交
- 当日奖励发放
- 当日活动参与

### 周报

- 周用户增长趋势
- 周行为提交趋势
- 周奖励发放趋势
- 周活动效果分析

### 月报

- 月度用户增长
- 月度行为分析
- 月度奖励统计
- 月度活动总结

## 🚀 API 接口

### 获取统计数据

```bash
GET /api/v1/admin/stats?days=7
Authorization: Bearer <admin-token>
```

### 获取分析数据

```bash
GET /api/v1/admin/analytics?start_date=2024-01-01&end_date=2024-01-31
Authorization: Bearer <admin-token>
```

### 激活营销活动

```bash
POST /api/v1/admin/activities/:id/activate
Authorization: Bearer <admin-token>
```

## 🎯 运营策略

### 提高活跃度

1. **定期活动**: 每周/每月固定活动
2. **节日活动**: 结合节日主题
3. **限时活动**: 营造紧迫感
4. **奖励梯度**: 合理设置奖励

### 用户增长

1. **邀请奖励**: 激励用户邀请
2. **新用户奖励**: 吸引新用户
3. **分享奖励**: 鼓励分享
4. **推荐奖励**: 推荐机制

### 用户留存

1. **每日签到**: 培养习惯
2. **连续奖励**: 激励持续参与
3. **成长体系**: 等级和成就
4. **个性化推荐**: 精准推荐
