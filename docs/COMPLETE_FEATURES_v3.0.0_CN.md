## 🎯 运营功能详解

### 营销活动系统

#### 活动类型
1. **签到活动**: 每日签到，连续签到获得递增奖励
2. **邀请活动**: 邀请新用户，双方获得奖励
3. **每日任务**: 完成指定任务获得奖励
4. **抽奖活动**: 参与抽奖获得随机奖励
5. **限时抢购**: 限时高额奖励，营造紧迫感
6. **节日活动**: 主题化节日活动

#### 运营策略
- **新用户激活**: 注册奖励、首次行为奖励
- **用户留存**: 每日签到、连续奖励、成长体系
- **用户增长**: 邀请奖励、分享奖励、推荐奖励
- **活跃度提升**: 每日任务、挑战活动、排行榜

### 链上数据监听

#### 监听内容
- **交易监听**: 奖励发放、存证、合约调用
- **账户监听**: 程序账户、用户账户、管理员账户
- **事件监听**: RewardMinted、ProofRecorded、ChallengeCompleted

#### 数据收集
- 实时数据：交易数量、金额、活跃用户
- 历史数据：每日统计、趋势分析、用户行为

#### 运营报告
- **日报**: 当日交易、新增用户、奖励发放
- **周报**: 周趋势、用户增长、活动效果
- **月报**: 月度总结、用户画像、运营建议

### 多链支持

#### 支持的链
- **Solana**: 高吞吐量、低费用（默认）
- **Ethereum**: 生态成熟、用户基数大
- **Polygon**: 低 Gas 费用、快速交易
- **BSC**: 低费用、高性能

#### 功能特点
- 用户可选择奖励发放的链
- 多链余额查询
- 统一的奖励发放接口
- 链上数据统计

### 合约升级管理

#### 升级流程
1. **检查升级**: 检查是否有可用升级
2. **验证升级**: 验证新程序兼容性
3. **准备升级**: 准备升级环境
4. **执行升级**: 安全执行升级
5. **验证结果**: 验证升级成功

#### 安全措施
- 权限控制（仅管理员）
- 多签验证（生产环境）
- 时间锁机制
- 回滚机制

## 🔧 配置说明

### 环境配置

项目默认部署在 **Solana 测试环境 (Devnet)**，通过 `ENVIRONMENT` 环境变量控制：

```bash
# 测试环境（默认）
ENVIRONMENT=test

# 主网环境
ENVIRONMENT=mainnet

# 开发环境
ENVIRONMENT=dev
```

### 多环境自动切换

- **Solana RPC URL**: 根据环境自动选择
- **奖励配置**: 主网可使用更高奖励
- **AI 阈值**: 主网使用更严格阈值
- **限流配置**: 主网可更宽松

## 🚀 快速开始

### 1. 配置环境

```bash
cp .env.example .env
# 编辑 .env，设置 ENVIRONMENT=test（默认）
```

### 2. 启动服务

```bash
# Docker 方式
docker-compose up -d

# 或本地运行
cd backend && go run main.go
```

### 3. 启动前端

```bash
cd frontend
npm install
npm start
```

### 4. 访问应用

- 后端 API: http://localhost:8080
- 前端应用: http://localhost:3000
- 健康检查: http://localhost:8080/api/v1/health
