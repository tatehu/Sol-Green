## 📋 文档规范 / Documentation Standards

### 版本命名 / Version Naming
- 格式: `文件名_v版本号_语言代码.md`
- 示例: `API_v3.0.0_CN.md`
- 语言代码: `CN` (中文), `EN` (英文)

### 文档结构 / Document Structure
1. **标题 / Title**: 文档主题
2. **概述 / Overview**: 功能简介
3. **功能特性 / Features**: 详细功能说明
4. **使用指南 / Usage**: 如何使用
5. **API 接口 / API**: 接口文档
6. **配置说明 / Configuration**: 配置选项
7. **示例代码 / Examples**: 代码示例
8. **常见问题 / FAQ**: 问题解答
9. **参考资料 / References**: 相关链接

### 更新记录 / Update Records
- 每次功能更新时创建新版本文档
- 保持历史版本文档可用
- 在 CHANGELOG 中记录变更
