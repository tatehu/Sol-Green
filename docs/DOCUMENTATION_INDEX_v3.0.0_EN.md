## 📋 Documentation Standards

### Version Naming
- Format: `filename_v_version_language.md`
- Example: `API_v3.0.0_CN.md`
- Language codes: `CN` (Chinese), `EN` (English)

### Document Structure
1. **Title**: Document theme
2. **Overview**: Feature introduction
3. **Features**: Detailed feature explanation
4. **Usage**: How to use
5. **API**: Interface documentation
6. **Configuration**: Configuration options
7. **Examples**: Code examples
8. **FAQ**: Problem solving
9. **References**: Related links

### Update Records
- Create new version documentation for each feature update
- Keep historical version documentation available
- Record changes in CHANGELOG
