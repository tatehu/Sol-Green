# 🌱 Sol-Green Environmental Reward Platform - Project Introduction

## 📌 Project Overview

Sol-Green is a decentralized environmental behavior recording and reward platform based on the Solana blockchain. Users earn token rewards by submitting environmental behaviors (waste sorting, tree planting, low-carbon travel, etc.). The platform uses AI fraud detection, on-chain proof storage, and third-party organization verification to ensure behavior authenticity and credibility.

### Core Values

- 🌍 **Environmental Incentives**: Motivate users to participate in environmental activities through token rewards
- 🔒 **Transparency & Trust**: All behaviors are recorded on the Solana blockchain, immutable and transparent
- 🤖 **Intelligent Review**: AI automatic detection, low-risk behaviors approved instantly
- 🎯 **Rich Activities**: Challenge activities and marketing campaigns increase engagement
- 🌐 **Multi-Chain Support**: Supports Solana, Ethereum, Polygon, BSC, and more

### Part 4: Technical Features

#### 14. AI Fraud Detection Flow

![AI Detection Flow](./assets/15_ai_detection_flow_EN.png)

**Detection Process Details:**

**Step 1: Image Recognition**
- Identify environmental behavior scenarios in images
- Verify image content matches behavior type
- Detect image quality and clarity

**Step 2: Duplicate Detection**
- Check for duplicate submissions of same content
- Compare with historical submission records
- Prevent malicious reward farming

**Step 3: Authenticity Verification**
- Detect if images have been PS processed
- Verify image capture time and location
- Analyze image metadata

**Step 4: Risk Assessment**
- Comprehensive scoring to calculate fraud score
- **Score < 0.3**: Low Risk, Auto Approved ✅
- **Score 0.3-0.7**: Medium Risk, Manual Review ⏳
- **Score > 0.7**: High Risk, Directly Rejected ❌

**Technical Features:**
- 🤖 Integrated with leading AI detection technologies: Baidu AI, Alibaba Cloud, AWS, Google Cloud
- 📊 Multi-dimensional comprehensive assessment
- ⚡ Real-time detection, second-level response
- 🔒 Protect user privacy and data security

## 🚀 Quick Start

### Requirements
- Go 1.21+
- Node.js 18+
- Docker & Docker Compose (Recommended)
- Solana CLI
- Anchor CLI

### Startup Steps

1. **Clone Project**
```bash
git clone <repository-url>
cd Solana-bootcamp-2026-s1-finalProject
```

2. **Configure Environment Variables**
```bash
cp .env.example .env
# Edit .env file with necessary configurations
```

3. **Start Backend Service**
```bash
docker-compose up -d
# Or run locally
cd backend
go run main.go
```

4. **Start Frontend Application**
```bash
cd frontend
npm install
npm start
```

5. **Access Application**
- Frontend: http://localhost:3000
- Backend API: http://localhost:8080

For detailed configuration instructions, please refer to: [Configuration Guide](./docs/CONFIG_SETUP_GUIDE_v3.0.0_EN.md)
